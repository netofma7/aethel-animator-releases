# AETHEL Animator — atualizações Android

Este repositório público é destinado **somente à distribuição de aplicativos APK assinados e verificáveis** do AETHEL Animator. O código-fonte de desenvolvimento fica separado em repositório privado.

## Downloads

Os instaladores oficiais aparecerão em [Releases](https://github.com/netofma7/aethel-animator-releases/releases) quando a primeira compilação **release assinada** for concluída.

Ao instalar uma atualização, confirme que ela mantém o mesmo identificador Android (`com.aethel.animator`) e a assinatura do aplicativo anterior. Faça backup de projetos e assets importantes antes de atualizar.
